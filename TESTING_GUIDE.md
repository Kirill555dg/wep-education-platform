# Руководство по тестированию сквозного сценария

## Цель
Протестировать полный цикл: создание класса → урока → ДЗ → выполнение студентом

## Предварительные требования

1. **Backend запущен:**
```bash
cd backend
# Убедитесь, что база данных запущена
cd ../database && make up

# Запустите backend
cd ../backend
uvicorn app.main:app --reload
```

2. **Frontend запущен с real API:**
```bash
cd frontend
# Создайте .env если еще не создан
echo "VITE_USE_REAL_API=true" > .env
echo "VITE_API_URL=http://localhost:8000" >> .env

# Запустите frontend
bun run dev
```

## Сквозной сценарий

### Шаг 1: Регистрация преподавателя

1. Откройте http://localhost:5173/register
2. Заполните форму:
   - Email: `teacher@test.com`
   - Password: `password123`
   - Роль: `Преподаватель`
   - Остальные поля по желанию
3. Нажмите "Зарегистрироваться"
4. После успешной регистрации войдите в систему

### Шаг 2: Создание курса (преподаватель)

1. Перейдите на `/teacher/manage`
2. **Создайте класс:**
   - Название: "Математика 10А"
   - Предмет: "Математика"
   - Описание: "Алгебра и начала анализа"
   - Нажмите "Создать класс"
   - **Сохраните код приглашения** (например, `ABC123XYZ`)

3. **Создайте урок:**
   - Название: "Тригонометрия"
   - Описание: "Основы тригонометрических функций"
   - Нажмите "Создать урок"

4. **Создайте задачи (минимум 2):**
   - Задача 1:
     - Название: "Вычислить sin(30°)"
     - Текст: "Найдите значение синуса 30 градусов"
     - Правильный ответ: "0.5"
   - Задача 2:
     - Название: "Вычислить cos(60°)"
     - Текст: "Найдите значение косинуса 60 градусов"
     - Правильный ответ: "0.5"

5. **Создайте домашнее задание:**
   - Название: "ДЗ #1: Тригонометрия"
   - Описание: "Базовые тригонометрические функции"
   - Нажмите "Создать ДЗ"
   - **Сохраните ID домашнего задания** (например, `1`)

### Шаг 3: Регистрация студента

1. Выйдите из системы (Logout)
2. Откройте http://localhost:5173/register
3. Заполните форму:
   - Email: `student@test.com`
   - Password: `password123`
   - Роль: `Студент`
4. Зарегистрируйтесь и войдите

### Шаг 4: Присоединение к классу (студент)

1. На странице `/student` нажмите "Присоединиться к классу"
2. Введите **код приглашения** из Шага 2
3. Нажмите "Присоединиться"
4. Класс должен появиться в списке

### Шаг 5: Выполнение домашнего задания (студент)

1. Перейдите на `/student/homework/{ID}` (используйте ID из Шага 2)
   - Например: `http://localhost:5173/student/homework/1`

2. Вы увидите список задач

3. **Решите задачи:**
   - Для "Вычислить sin(30°)": введите `0.5` и нажмите "Отправить"
   - Для "Вычислить cos(60°)": введите `0.5` и нажмите "Отправить"

4. После каждого ответа должно появиться сообщение с текущим баллом

5. Нажмите "Завершить задание"

6. Вы должны увидеть итоговый результат

## Проверка результатов

### Через Swagger UI (Backend)

1. Откройте http://localhost:8000/api/docs
2. Авторизуйтесь через кнопку "Authorize" (используйте JWT токен из localStorage)
3. Проверьте эндпоинты:
   - `GET /api/v1/statistics/homework/{homework_id}` — статистика по ДЗ
   - `GET /api/v1/statistics/student/{student_id}` — статистика студента

### Через базу данных

```bash
cd database
make exec

# В psql:
SELECT * FROM homeworks;
SELECT * FROM statistics;
SELECT * FROM homework_problems;
```

## Ожидаемые результаты

- ✅ Класс создан с уникальным invite_code
- ✅ Урок привязан к классу
- ✅ Задачи созданы и привязаны к ДЗ
- ✅ ДЗ создано и доступно студенту
- ✅ Студент присоединился к классу
- ✅ Студент видит задачи (без правильных ответов)
- ✅ Ответы сохраняются в БД
- ✅ Статистика обновляется в реальном времени
- ✅ Финальный балл рассчитывается корректно

## Возможные проблемы

1. **401 Unauthorized**: Убедитесь, что вы залогинены
2. **403 Forbidden**: Проверьте роль пользователя (teacher/student)
3. **404 Not Found**: Проверьте ID ресурсов
4. **CORS errors**: Убедитесь, что backend разрешает запросы с localhost:5173
