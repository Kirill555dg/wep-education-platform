Описание проекта
================

Web Education Platform - это система управления онлайн-обучением (LMS), построенная на основе
современных технологий и архитектурных паттернов.

Основные технологии
-------------------

* **FastAPI** - асинхронный веб-фреймворк для создания REST API
* **SQLAlchemy 2.0** - ORM для работы с базой данных PostgreSQL
* **Pydantic** - валидация данных и схемы API
* **Alembic** - миграции базы данных
* **Redis** - кеширование и real-time функциональность

Архитектурные паттерны
----------------------

* **Многослойная архитектура**: разделение на слои API, сервисов и репозиториев
* **Service Layer Pattern**: бизнес-логика изолирована в сервисах
* **Repository Pattern**: абстракция доступа к данным
* **DTO (Data Transfer Objects)**: использование Pydantic-схем для передачи данных
* **Dependency Injection**: внедрение зависимостей через FastAPI

Доменная модель
---------------

Основные сущности системы:

* **User** - пользователь системы (преподаватель или студент)
* **Teacher** - профиль преподавателя
* **Student** - профиль студента
* **Classroom** - класс (группа студентов)
* **Lesson** - урок
* **Homework** - домашнее задание
* **Problem** - задача в домашнем задании
* **TheoryMaterial** - теоретический материал
* **Statistics** - статистика прохождения
