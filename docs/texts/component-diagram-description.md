Диаграмма компонентов системы (см. на рисунке 3.1) фиксирует состав основных компонентов WEP LMS и их взаимодействие в рамках клиент–серверной модели, включая каналы связи и тип передаваемых данных.

- **GUI (Web Client, React/TS SPA)** — клиентское веб‑приложение, предоставляющее пользовательский интерфейс для сценариев ролей «преподаватель» и «студент». Получает от пользователя команды и вводимые данные; передаёт на сервер запросы по HTTP/REST (JSON) и получает ответы, а для чата устанавливает WebSocket‑соединение и обменивается событиями.

- **FastAPI Application (routers + dependencies + WS)** — серверный компонент, реализующий единый программный интерфейс системы и предоставляющий два внешних интерфейса: HTTP/REST API (JSON) и WebSocket‑канал чата. Получает DTO/параметры запросов и WS‑события; вызывает прикладные сервисы и возвращает клиенту JSON‑ответы либо чат‑события.

- **AuthService** — сервис аутентификации и сессии (регистрация/вход, выпуск и проверка JWT, актуальная роль пользователя). Получает учётные данные и токен; возвращает токен и данные пользователя, читая/изменяя записи пользователей и профилей в PostgreSQL.

- **Access control helpers (services/access_control.py)** — набор доменных проверок доступа, используемый прикладными сервисами (например: «пользователь — преподаватель», «преподаватель владеет классом»). Получает уже загруженные доменные объекты/контекст; выдаёт разрешение или ошибку доступа, не являясь самостоятельным шлюзом к данным.

- **ClassroomService** — сервис управления классами и членством (создание класса, вступление по invite‑коду, получение списков классов/учеников). Получает команды и параметры выборки; возвращает данные классов и участников, изменяя записи классов, инвайтов и членства в PostgreSQL.

- **LessonService** — сервис управления уроками в рамках класса (создание, публикация, получение списка и деталей). Получает идентификатор класса/урока и параметры выборки; возвращает данные уроков и привязки материалов из PostgreSQL.

- **HomeworkService** — сервис управления домашними заданиями (создание, публикация, обновление, выдача состава задач). Получает команды учителя и идентификаторы урока/ДЗ; возвращает метаданные ДЗ и список задач, используя записи ДЗ и связей “ДЗ–задачи” в PostgreSQL.

- **ProblemService** — сервис базы задач (создание/редактирование/получение задач). Получает команды CRUD и параметры выборки; возвращает описания задач, используя записи задач в PostgreSQL.

- **TestingService** — сервис приёма ответов и автоматической проверки. Получает ответы ученика по задачам ДЗ; возвращает обновлённую статистику попытки (баллы/статус/число попыток/время), обновляя записи статистики в PostgreSQL.

- **ResultService (progress/statistics)** — сервис выдачи прогресса и статистики (по студенту и по ДЗ, а также агрегаты по классу). Получает запросы на выборку и агрегацию; возвращает показатели выполнения на основе записей статистики и членства в PostgreSQL.

- **TheoryService** — сервис теоретических материалов, привязанных к урокам. Получает идентификаторы уроков/материалов; возвращает структуру и содержимое материалов из PostgreSQL.

- **ChatService (HTTP chat history)** — сервис хранения и выдачи истории сообщений чата класса по HTTP. Получает команды чтения/создания сообщений и контекст пользователя; возвращает список сообщений и подтверждение сохранения, используя записи чатов и сообщений в PostgreSQL.

- **Realtime chat runtime (manager + broker)** — подсистема доставки чат‑событий в реальном времени и поддержки краткоживущих состояний (presence/typing). Получает события от WebSocket‑обработчиков; рассылает события участникам и использует Redis для Pub/Sub и хранения краткоживущих ключей.

- **Repositories (app/repositories/*)** — слой доступа к данным, инкапсулирующий SQL‑запросы к доменным таблицам. Получает запросы от сервисов и SQLAlchemy‑сессию; возвращает доменные объекты и результаты выборок.

- **SQLAlchemy AsyncSession (db/session.py)** — компонент управления транзакциями и подключениями к БД в рамках запроса. Получает запрос на создание сессии от FastAPI dependency; предоставляет репозиториям контекст выполнения SQL‑операций.

- **PostgreSQL** — компонент персистентного хранения и источник истины доменных данных LMS. Получает операции чтения/записи от репозиториев; хранит сущности пользователей, классов, уроков, ДЗ, задач, сообщений и статистики.

- **Redis (Pub/Sub + ephemeral presence)** — инфраструктурный компонент, используемый realtime‑подсистемой чата. Получает публикации событий и операции над краткоживущими ключами; предоставляет Pub/Sub‑доставку событий и данные presence/typing.
