## 📋 Подготовка к тестированию

### 1. Запуск системы

```bash
# Убедитесь, что PostgreSQL запущен
cd /Users/kerrodar/Dev/wep-education-platform
make db-up

# Запустите backend
cd backend
source venv/bin/activate
uvicorn app.main:app --reload

# В новом терминале запустите frontend
cd frontend
bun run dev
```

### 2. Очистите localStorage в браузере

⚠️ **ВАЖНО!** Перед тестированием:

1. Откройте DevTools (F12)
2. Console → выполните: `localStorage.clear()`
3. Обновите страницу (Ctrl+R / Cmd+R)

## 🎓 Сценарий 1: Полный flow преподавателя

### Шаг 1: Регистрация преподавателя

1. Откройте `http://localhost:5173/register`
2. Заполните форму:
   - **Email:** `teacher@test.com`
   - **Пароль:** `password123`
   - **Роль:** `Teacher`
   - **Имя:** `Иван`
   - **Фамилия:** `Иванов`
3. Нажмите "Зарегистрироваться"

✅ **Ожидаемый результат:**
- Переход на `/teacher`
- В шапке badge "Преподаватель" (синий)
- Пустое состояние "У вас пока нет классов"

---

### Шаг 2: Создание класса

1. Нажмите "Создать класс"
2. Заполните форму:
   - **Название:** `Математика 10А`
   - **Предмет:** `Математика`
   - **Описание:** `Алгебра и начала анализа`
3. Нажмите "Создать"

✅ **Ожидаемый результат:**
- Toast "✅ Класс создан!"
- Карточка класса появилась
- Отображается код приглашения (например, `ABC123`)
- Показано "0 учеников"

---

### Шаг 3: Создание урока

1. Кликните на карточку класса "Математика 10А"
2. Нажмите "Создать урок"
3. Заполните форму:
   - **Название:** `Квадратные уравнения`
   - **Описание:** `Решение квадратных уравнений`
4. Нажмите "Создать урок"

✅ **Ожидаемый результат:**
- Toast "✅ Урок создан!"
- Урок появился в списке
- Можно кликнуть на урок

---

### Шаг 4: Создание домашнего задания

1. Кликните на урок "Квадратные уравнения"
2. Нажмите "Создать ДЗ"
3. Заполните форму:
   - **Название:** `Решение уравнений`
   - **Описание:** `Решите 10 уравнений`
   - **Максимальный балл:** `100`
4. Нажмите "Создать ДЗ"

✅ **Ожидаемый результат:**
- Toast "✅ Домашнее задание создано!"
- ДЗ появилось в списке
- Показано "Задач: 0"
- Кнопка "Управление"

---

### Шаг 5: Добавление задач к ДЗ

1. Нажмите "Управление" на карточке ДЗ
2. Откроется страница управления ДЗ
3. Нажмите "Создать задачу"
4. Заполните форму:
   - **Название:** `Решите уравнение x² - 5x + 6 = 0`
   - **Описание:** `Найдите все корни уравнения`
   - **Тип задачи:** `Короткий ответ`
   - **Сложность:** `Средняя`
   - **Правильный ответ:** `x = 2, x = 3`
   - **Объяснение:** `Разложим на множители: (x-2)(x-3)=0`
5. Нажмите "Создать задачу"

✅ **Ожидаемый результат:**
- Toast "✅ Задача создана!"
- Задача появилась в списке
- Показан правильный ответ (только для преподавателя)

6. Создайте ещё 2-3 задачи для разнообразия

---

### Шаг 6: Получение кода приглашения

1. Вернитесь на `/teacher` (через хлебные крошки или кнопку назад)
2. На карточке класса скопируйте код приглашения (например, `ABC123`)

✅ **Сохраните этот код** - он понадобится для тестирования студента!

## 🎒 Сценарий 2: Полный flow студента

### Шаг 1: Переключение на роль студента

**Вариант А: Тот же пользователь (рекомендуется)**

1. Зайдите в `/profile`
2. Нажмите зелёную кнопку "Ученик"
3. Badge в шапке изменится на "Ученик" (зелёный)
4. Переход на `/student`

**Вариант Б: Новый пользователь**

1. Выйдите из системы (Logout)
2. Зарегистрируйтесь с ролью `Student`:
   - **Email:** `student@test.com`
   - **Пароль:** `password123`
   - **Роль:** `Student`
   - **Имя:** `Пётр`
   - **Фамилия:** `Петров`

✅ **Ожидаемый результат:**
- Badge "Ученик" (зелёный) в шапке
- Страница `/student`
- Пустое состояние "Вы пока не присоединились ни к одному классу"

---

### Шаг 2: Присоединение к классу

1. Нажмите "Присоединиться к классу"
2. Введите код приглашения (который скопировали ранее, например `ABC123`)
3. Нажмите "Присоединиться"

✅ **Ожидаемый результат:**
- Toast "✅ Вы присоединились к классу!"
- Класс "Математика 10А" появился в списке
- Показано количество учеников

---

### Шаг 3: Просмотр уроков

1. Кликните на класс "Математика 10А"
2. Откроется страница класса со списком уроков

✅ **Ожидаемый результат:**
- Урок "Квадратные уравнения" виден
- Можно кликнуть на урок

---

### Шаг 4: Просмотр домашних заданий

1. Кликните на урок "Квадратные уравнения"
2. Откроется список ДЗ для этого урока

✅ **Ожидаемый результат:**
- ДЗ "Решение уравнений" отображается
- Показано количество задач
- Статус (например, "Не начато")

---

### Шаг 5: Выполнение домашнего задания

1. Кликните на ДЗ "Решение уравнений"
2. Откроется страница выполнения ДЗ
3. Для каждой задачи:
   - Прочитайте условие
   - Введите ответ в поле
   - Нажмите "Отправить ответ"

✅ **Ожидаемый результат:**
- После каждого ответа: Toast "✅ Ответ отправлен!"
- Показан текущий балл
- Прогресс-бар обновляется
- Ответы автоматически сохраняются в localStorage

4. Ответьте на все задачи

✅ **Финальный результат:**
- Все задачи отмечены как выполненные
- Показан финальный балл
- "Празднование" при завершении
